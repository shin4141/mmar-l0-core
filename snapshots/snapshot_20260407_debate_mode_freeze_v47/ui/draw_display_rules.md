# Draw Display Rules

## Public-facing Draw copy

- Primary line:
  - `今回は片側を勝ちにするより、保留の方が妥当`

## Public-facing winner copy

- When a Draw is resolved by the narrow tiebreak:
  - `相手の主張の土台を崩した点を決め手とした`

## Internal term rewrite

- `constitutive_break`
  - Public wording: `相手の主張の土台を崩した`
- `unclear`
  - Public wording: `保留が妥当`
- block reasons
  - Do not expose directly in public copy

## Intent

- Draw is not failure.
- Draw is not indecision.
- Draw is shown as a deliberate hold when forcing a winner would be less honest.
